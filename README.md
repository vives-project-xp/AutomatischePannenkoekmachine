# De automatische pannenkoekmachine

Welkom op de projectpagina van onze automatische pannenkoekmachine.

Wij ontwerpen en bouwen een machine die zelfstandig deeg doseert, een pannenkoek bakt, deze omdraait en daarna van de bakplaat verwijdert. Met dit project brengen we mechanica, elektronica en software samen in één geautomatiseerd systeem.
